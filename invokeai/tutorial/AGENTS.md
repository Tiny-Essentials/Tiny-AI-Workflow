# invokeai/tutorial/

Step-by-step InvokeAI guides.

- File name = technique, not the model (`two-pass-composition.md`, not
  `sdxl-test-3.md`).
- Structure: `# Title`, `## Scope`, numbered sections, `## Checklist` at the end.
- State which InvokeAI version the screenshots/steps refer to.
- If a step depends on a custom node, link to the node repository.
