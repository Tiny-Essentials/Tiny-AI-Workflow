# invokeai/

Tutorials and workflows for **InvokeAI** (image generation frontend).

## Rules

- One tutorial per file, `kebab-case.md`, inside `tutorial/`.
- Every tutorial starts with the goal, then the prerequisites, then the steps.
- Screenshots go to an external host; this repository does not accept new
  binaries.
- Prompts and negative prompts go in fenced blocks with the `text` language.
- Content may be adult-adjacent fiction: keep it technical, keep it separated
  from `agents/` and from any professional context.
