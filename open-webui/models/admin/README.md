# OpenWebUI Model Configurations

This directory contains a collection of model configuration files designed for use with [OpenWebUI](https://github.com/open-webui/open-webui). These configurations allow you to quickly set up optimized parameters for various models.

## 🚀 Instructions

To use the configurations provided in this folder, you **must** follow these steps in the correct order:

### 1. Install the Model in your Provider
Before importing any configuration, ensure that the actual model is already installed and running on your backend provider (e.g., **Ollama**, **OpenAI**, **LocalAI**, etc.). 

> **Note:** The files in this folder are only settings/instructions; they do not contain the model weights themselves.

### 2. Import the Configuration to OpenWebUI
Once the model is available in your provider, follow these steps:
1. Open your **OpenWebUI** interface.
2. Navigate to the **Models** section.
3. Select the option to **Import Model** or create a new model.
4. Upload or paste the configuration file from this folder that corresponds to the model you have installed.
