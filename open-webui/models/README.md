# OpenWebUI Model Configurations (Root)

This directory is the central repository for model configuration files intended for use with [OpenWebUI](https://github.com/open-webui/open-webui).

## 🧭 Navigation Guide

To ensure the configurations are applied to the correct section of your OpenWebUI instance, please navigate to the appropriate sub-folder based on your intent:

### 1. For "Models" Session Configurations
If you intend to configure models for the global **Models** session:
*   **Go to:** `admin/`
*   **Use case:** These configurations are intended for administrative-level model management.

### 2. For "Workspace" Session Configurations
If you intend to configure models for the **Workspace** session:
*   **Go to:** `personal/`
*   **Use case:** These configurations are intended for personal model customization within your workspace.

---

## 📂 Directory Structure
```text
open-webui/models/
├── admin/      # Configurations for the "Models" session
└── personal/   # Configurations for the "Workspace" session
```
