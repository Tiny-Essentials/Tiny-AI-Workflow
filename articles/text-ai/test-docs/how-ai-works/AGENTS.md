# how-ai-works/

Chapter-per-file explainer series about LLM internals.

| File | Chapter |
| :--- | :--- |
| `ai-thinking-stuff(pt-br).md` | Reasoning / chain of thought. |
| `ai-auto-config(pt-br).md` | Automatic parameter selection. |
| `config-tips(pt-br).md` | Practical configuration tips. |
| `main-profiles(pt-br).md` | Model profiles and when to use each. |
| `max-token-to-coders(pt-br).md` | Token limits for coding. |
| `personality-params(pt-br).md` | Temperature, top-p, penalties. |
| `advanced-stuff(pt-br).md` | Everything that did not fit above. |

## Rules

- One concept per file. If a chapter grows past ~300 lines, split it.
- Cross-link chapters with relative links, never with absolute URLs.
