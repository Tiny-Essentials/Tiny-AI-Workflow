# articles/

Long-form, human-readable text. No code, no configuration.

## Rules

- One topic per file, `kebab-case.md`, title in the first `# H1`.
- `(WIP)` suffix while unfinished, `(pt-br)` when the text is in Portuguese.
- Opinion pieces keep the author's voice. Do not rewrite for neutrality.
- Facts, benchmarks and quotes need a source link at the bottom of the section.
- `text-ai/` holds AI theory/explainers; `test-docs/` holds drafts used to test
  models and is not meant to be read as a finished article.

## Adding an article

1. Create `articles/<slug>.md` (or `articles/text-ai/<slug>.md`).
2. Link it from the root [`README.md`](../README.md) if it is finished.
