# librechat/skills/

Self-contained skills for LibreChat.

- File name: `<topic>(pt-br).md` when the skill must answer in Portuguese.
- Required sections: `## Name`, `## Description`, `## System Prompt`.
- The skill must work when pasted alone — no reference to files in this repo.
- Code examples inside the skill follow the same rules as the root `AGENTS.md`
  (English identifiers, English comments).
